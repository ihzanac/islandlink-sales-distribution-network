## 🌟 System Overview

**ISDN (IslandLink Sales Distribution Network)** is a centralized web-based sales distribution management system designed to digitalize and simplify the complete product distribution process.

The system connects:

* 👤 Customers
* 🏢 Regional Distribution Centres (RDCs)
* 🚚 Logistics Teams
* 👨‍💼 Administrators
* 📦 Products
* 🛒 Orders
* 💳 Payments
* 🚛 Deliveries

through a single integrated digital platform.

The system provides a centralized environment for managing product ordering, inventory, order processing, payment, delivery coordination, GPS-based monitoring, customer reviews, returns and management reporting.

### ISDN helps users to:

* 👤 Create and manage customer accounts
* 📦 Browse available products
* 🔍 Search and view product information
* 🛒 Add products to cart
* 📝 Place orders online
* 💳 Make online payments
* 📋 Track order history
* 🚚 Monitor delivery progress
* 🗺️ Track delivery locations using GPS
* 🏢 Manage Regional Distribution Centres
* 📦 Monitor inventory
* 🔄 Manage stock between RDCs
* 🚛 Manage shipments and fleet operations
* ⭐ Submit product reviews
* ↩️ Request product returns
* 📊 Generate management reports
* 🔐 Manage role-based system access

The system is designed to replace manual distribution processes with a centralized digital platform that improves order visibility, inventory management, delivery coordination and operational efficiency.

# 🔑 Environment Configuration

Sensitive configuration should be stored in environment variables.

Example structure:

```env
FIREBASE_API_KEY=your_firebase_api_key
FIREBASE_AUTH_DOMAIN=your_firebase_auth_domain
FIREBASE_PROJECT_ID=your_firebase_project_id
FIREBASE_STORAGE_BUCKET=your_firebase_storage_bucket
FIREBASE_MESSAGING_SENDER_ID=your_firebase_sender_id
FIREBASE_APP_ID=your_firebase_app_id

GOOGLE_MAPS_API_KEY=your_google_maps_api_key

PAYHERE_MERCHANT_ID=your_payhere_merchant_id
PAYHERE_SECRET=your_payhere_secret

PAYPAL_CLIENT_ID=your_paypal_client_id
PAYPAL_SECRET=your_paypal_secret
```

> ⚠️ Never upload real API keys, passwords, payment credentials or private secrets to GitHub.
